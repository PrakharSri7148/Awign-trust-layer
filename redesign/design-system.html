Trust Layer design system

Flat, quiet, enterprise-dark. One accent. Semantic color only as small tinted pills. Every value below is a CSS variable in css/tokens.css.

Inter (self-hosted, variable). Tabular numerals for numbers; mono only for IDs and coordinates. 12px is the smallest size anywhere.

8px radius. Blue is reserved for the one primary action and Refresh. Danger lives in Settings, never in a case file.

Outlined 1px with a faint tint, always with a word. Severity follows the fraud probability: 80% and above Critical, 60–79% High, 40–59% Medium, below 40% Low.
